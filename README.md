### Reach Artificial

# Description

Reach Artificial is a Internet of Things tool that connects local Artificial Intelligence conveinently 
with an external device such as your phone or tablet

## Development Plan

1. Research tools and libraries needed
2. Figure out a secure connection between device and server 
    a. set up user side and sever side connections (tailwind)
3. Create basic app to send text to server
4. set up LLM API
5. Figure out how to get LLM to work with those inputs and send it back 
6. Now worry about security
